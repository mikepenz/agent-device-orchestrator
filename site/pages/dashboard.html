Live dashboard

A local page for devices, queue, timeline and the run log.

Server

devq live serves on 127.0.0.1 only and returns 403 unless the Host header is 127.0.0.1:<port> or localhost:<port> (DNS rebinding guard). GET / is the page, GET /api/state?window=<secs> returns JSON. Append ?mock=1 for the built-in simulator.

The page shows Devices, Queue, Timeline (1h, 6h, 24h), a stat strip, the Runs log, and per-device and per-agent tables. Blocked hook attempts appear too.

Run it as a Mac app

cargo install --path .      # a stable binary path for launchd
devq service install        # LaunchAgent: starts at login, restarts on crash (--port, default 7878)

Open http://127.0.0.1:7878/ and install the page: Chrome menu, "Install devq live", or Safari, File, "Add to Dock". devq service status shows the launchd state, restart after upgrading the binary, uninstall removes it. Logs go to ~/.devq/live.log. macOS only; elsewhere run devq live under systemd --user.

Query the database

The database is plain SQLite. Hold time per agent:

sqlite3 ~/.devq/devq.db "SELECT agent, COUNT(*) AS grants, SUM(released_at - granted_at) / 1000.0 AS held_s
  FROM slots WHERE released_at IS NOT NULL AND granted_at IS NOT NULL GROUP BY agent ORDER BY held_s DESC"

Columns of slots include state, end_reason (released, timeout, orphaned, cancelled, abandoned), command and exit_code. Times are unix milliseconds.
