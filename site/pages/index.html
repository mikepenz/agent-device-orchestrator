device-pool-orchestrator

A fair queue for shared Android devices between AI agents. One binary, no daemon. The command is devq.

Several agents, a few emulators and phones. devq gives each request a ticket, serves them in order, and holds the device for exactly as long as the work runs. Every devq process coordinates through one SQLite file in ~/.devq, so there is nothing to start or keep alive.

Quickstart

Install.

cargo install --git https://github.com/mikepenz/agent-device-orchestrator --locked

Prebuilt archives for macOS, Linux and Windows are on the releases page.

Teach your agents to use it.

devq skills add

Run something on a device, then watch it.

devq run --agent me --purpose "read model" -- adb shell getprop ro.product.model
devq live --open

What you get

No daemonThe database is the coordinator.
Fair FIFO queueRequests get tickets and are served in order. A pinned request never blocks the ones behind it.
devq runWraps any command, holds the lock for its lifetime, kills the whole process group at --max.
Live dashboardDevices, queue, timeline and run log on a local page.
Agent skillTeaches Claude Code and other agent tools to take a slot first.
Optional hookBlocks raw adb calls that have no slot. A guardrail, not a sandbox.
