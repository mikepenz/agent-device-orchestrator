Commands

Everyday use is devq run. The rest is for interactive sessions and inspection.

Everyday

devq devices                      # what the pool contains
devq run --agent me --purpose "instrumented tests" -- ./gradlew connectedDebugAndroidTest
devq request --agent me --purpose "manual poking"   # prints "<slot> <serial>"
devq release 2                                      # give the slot back
devq live --open                  # dashboard in the browser

devq run sets ANDROID_SERIAL, DEVQ_DEVICE and DEVQ_SLOT for the command, so use adb -s "$ANDROID_SERIAL" and never "whatever is attached".

Slot flags

For request and run.

FlagDefaultMeaning
--agentenv DEVQ_AGENTWho is asking. Required, except with --ticket.
--purposenoneWhy. Required, except with --ticket.
--description""What the work does.
--expect10mExpected hold time.
--max30mHard limit, at least --expect. Enforced.
--deviceanyPin to one serial.

Durations: 90s, 10m, 1h30m, 2d (units ms, s, m, h, d, w).

Command list

CommandWhat it does
devq requestQueue for a device and block until granted. Also --wait, --ticket, --json.
devq release <ID>Release an active slot or cancel a waiting one.
devq run -- <CMD>Acquire, run, release. Exits with the command's exit code.
devq statusDevices, holders and queue. --json available.
devq devicesPool contents: serial, kind, state, model.
devq liveWeb dashboard. --port (47878), --open.
devq serviceRun devq live as a macOS launchd service.
devq skillsInstall and manage the bundled agent skill.
devq hookOptional guardrail against raw adb.

Exit codes

0Granted. For run, the command's own code.
75--wait expired. request prints ticket <id>; re-run with --ticket <id> within about 30s to keep your place.
2Bad arguments.
1Unknown or finished slot, or another error.
124run: --max killed a command that otherwise exited 0.
127run: the command could not start.
128+nrun: the child died from signal n.

Config

$DEVQ_HOME/config.toml, optional, re-read on every command. Globs support *. Unknown keys are an error.

[pool]
include = ["emulator-*"]    # empty means everything adb reports
exclude = ["emulator-5556"]
static  = ["rig-a"]         # non-adb resources, always online
